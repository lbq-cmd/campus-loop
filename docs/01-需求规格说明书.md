# 需求规格说明书

**项目名称**：低碳校园资源循环流转桌面系统
**文档版本**：v1.2（迭代二基线）
**编写日期**：2026-11
**适用阶段**：迭代一需求分析定稿，迭代二按本规格实现核心业务模块

---

## 1. 项目背景与目标

当前校园存在大量闲置教材、数码配件、文体用品、生活物资闲置浪费，二手流转信息零散，
缺少轻量化本地桌面管理系统。本系统面向高校校园，实现闲置物品发布、分类检索、供需匹配、
交易记录、信用评价、数据统计与管理员后台管理，形成完整业务闭环，并可打包为 Jar 直接部署运行。

**建设目标**

1. 为学生提供"发布—检索—沟通—流转—互评"的完整二手流转闭环；
2. 为管理员提供用户管理、违规物品下架、分类维护与全平台统计能力；
3. 以 SQLite 本地数据库实现零安装部署，数据可备份、可迁移；
4. 通过分层架构、设计模式与单元测试，体现软件构造课程要求的可维护性与可扩展性。

## 4. 非功能需求

| 编号 | 类别 | 要求 |
| --- | --- | --- |
| NFR-01 | 性能 | 本地 1 万条物品数据下，条件检索响应 ≤ 1s；启动 ≤ 3s |
| NFR-02 | 安全 | 密码不可逆存储；全部 SQL 预编译；界面输入做长度与类型校验；管理员操作鉴权 |
| NFR-03 | 可靠性 | 关键写操作在事务中完成，异常自动回滚；数据库损坏时可从备份恢复 |
| NFR-04 | 可维护性 | 分层清晰、依赖倒置；新增排序/校验规则不改动既有调用方；单方法 ≤ 60 行 |
| NFR-05 | 可测试性 | 业务层不依赖界面与真实数据库文件，可在临时库上跑单元测试 |
| NFR-06 | 可移植性 | Windows / macOS / Linux 均可运行；仅依赖 JRE 11+ |
| NFR-07 | 易用性 | 中文界面；错误提示面向用户而非堆栈；危险操作需确认 |
| NFR-08 | 日志 | 关键业务操作记录到 logs/campusloop.log，含时间、级别、操作者与结果 |

## 5. 主要业务规则汇总

1. **唯一性**：用户名、分类名全局唯一（数据库唯一约束 + 服务层预检）。
2. **状态机**：物品 `ONLINE → OFF_SHELF → ONLINE`；`ONLINE → LOCKED → SOLD`；任意状态 → `REMOVED`（管理员）。
3. **归属**：编辑、下架、重新上架只能由发布者执行；管理员仅可强制移除与编辑修正。
4. **价格**：出售 > 0；交换/赠送 = 0；上限 100000。
5. **信用**：区间 [0,150]，越界自动截断；封禁用户不可登录、不可发布与收藏。
6. **检索**：默认仅返回 `ONLINE`；关键词对标题、描述、标签做包含匹配，`%`、`_` 按普通字符处理。
7. **收藏**：仅可收藏在架物品；收藏记录随物品删除级联清理。

## 6. 迭代二验收标准

1. 用户、物品、分类、收藏四条主线的增删改查与业务规则全部可用，并可通过控制台演示；
2. `mvn clean test` 全绿，单元测试覆盖公共工具、DAO、服务层与事务；
3. 数据库初始化脚本可重复执行，首启自动建库并写入默认分类与演示管理员；
4. 非法输入、越权操作、重复数据、外键错误均有明确异常与提示，不出现未捕获堆栈；
5. 代码通过 Maven 编译打包，README 与设计文档与实现一致。
