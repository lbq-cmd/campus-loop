## 2. 测试方法

1. **等价类划分 + 边界值**：用户名长度 3/4/20/21、密码 7/8/32/33、价格 0/100000/100001、标签 5/6 个、标签长度 12/13。
2. **异常路径优先**：每个业务规则至少配一条失败用例（非法输入、越权、重复、状态不符、数据不存在）。
3. **真实数据库**：每个测试方法在临时目录新建独立 SQLite 库并执行与交付一致的 `schema.sql`，
   不使用 Mock，保证 SQL、约束、字段映射被真实执行；测试结束删除临时库。
4. **事务测试**：在事务中制造外键冲突与业务异常，验证整批写入回滚。
5. **安全相关**：验证错误密码与不存在用户返回同一提示；验证 `%`、`_` 被当作普通字符；
   验证数据库只存 PBKDF2 密文且两次加密结果不同。

## 6. 缺陷与问题记录（开发—测试过程中发现并修复）

| 编号 | 现象 | 原因 | 修复 |
| --- | --- | --- | --- |
| D-01 | 所有插入用例报 `SQLFeatureNotSupportedException: not implemented by SQLite JDBC driver` | SQLite JDBC 驱动未实现 `PreparedStatement.getGeneratedKeys()` | 改为在同一连接执行 `SELECT last_insert_rowid()` 读取主键，并补充注释说明原因 |
| D-02 | 编译报错"switch 表达式需要 -source 14" | 演示入口误用 Java 14+ 语法，而项目按课程环境编译到 Java 11 | 改为传统 `switch` 语句，保证 Java 11 兼容 |
| D-03 | 首次运行出现"日志文件初始化失败"告警且日志重复两行 | `logs/` 目录不存在；同时保留了 JDK 默认 ConsoleHandler | 启动前 `Files.createDirectories`，并移除默认 handler 后只挂载自定义 handler |
| D-04 | 多个 DAO 测试初始化时报分类唯一约束冲突 | 测试夹具重复插入 `seed.sql` 已存在的分类 | 夹具改为"存在即复用，否则新建" |
| D-05 | 覆盖率报告为空 | surefire 显式 `argLine` 覆盖了 JaCoCo 注入的 agent 参数 | 改为 `@{argLine} -Dfile.encoding=UTF-8` 合并参数 |

> D-01 ~ D-04 均已通过回归测试；D-05 为构建配置问题，不影响业务。

## 8. 结论

迭代二所有交付代码通过单元测试，86/86 用例成功；核心服务层行覆盖率 96% 以上，
业务规则（身份鉴权、价格规则、状态机、归属权限、收藏幂等、检索安全）均有对应用例守护。

当前质量满足进入迭代三（GUI 与系统集成）的条件。
